Phụ lục C

Lộ trình học tiếp

Hoàn thành Machine Learning Specialization là nền móng vững chắc. Đây là những hướng đi tiếp theo, kèm tài liệu đáng đọc.

1. Củng cố nền tảng toán

  • Đại số tuyến tính: ma trận, vector riêng, SVD — nền của PCA, embeddings, mọi phép toán trong mạng nơ-ron. 3Blue1Brown — Essence of Linear Algebra (video trực quan).
  • Giải tích nhiều biến: gradient, quy tắc chuỗi, Jacobian — nền của backprop.
  • Xác suất thống kê: phân phối, kỳ vọng, MLE, Bayes — nền của loss function, anomaly detection, mô hình sinh.
  • Mathematics for Machine Learning (Deisenroth, Faisal, Ong) — sách miễn phí.

2. Machine learning cổ điển sâu hơn

  • SVM (support vector machine) và kernel trick — có trong bản cũ của khoá Andrew Ng (2011).
  • Naive Bayes, k-NN, Gaussian Mixture Models, EM algorithm.
  • Thực hành nhiều với scikit-learn, pandas, XGBoost/LightGBM trên Kaggle.
  • Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow (Aurélien Géron) — sách thực hành rất tốt.
  • An Introduction to Statistical Learning (ISLP, có bản Python, miễn phí).

3. Deep Learning

  • Deep Learning Specialization (Andrew Ng, DeepLearning.AI) — bước tiếp theo tự nhiên: tối ưu hoá, CNN, RNN, attention.
  • PyTorch: framework phổ biến nhất trong nghiên cứu hiện nay. Khoá fast.ai — Practical Deep Learning for Coders dạy theo hướng “làm trước, lý thuyết sau”.
  • CNN cho thị giác máy tính: phân loại ảnh, phát hiện vật thể (YOLO), phân đoạn (U-Net).
  • Transformer: bài báo Attention Is All You Need (2017); khoá Stanford CS224N (NLP) và CS231n (thị giác).
  • Dive into Deep Learning (d2l.ai) — sách miễn phí, có code PyTorch/TensorFlow.

4. Generative AI & LLM

  • Kiến trúc GPT, pre-training, fine-tuning, RLHF (xem chương 17).
  • Prompt engineering, RAG (retrieval-augmented generation — dùng vector search như chương 16), agents và tool use.
  • Fine-tuning hiệu quả: LoRA, QLoRA. Thư viện Hugging Face Transformers.
  • Mô hình khuếch tán (diffusion) cho sinh ảnh.
  • Các khoá ngắn miễn phí của DeepLearning.AI về LLM và agents; Andrej Karpathy — Neural Networks: Zero to Hero (tự xây GPT từ đầu).

5. MLOps — đưa mô hình vào thực tế

  • Quản lý thí nghiệm: MLflow, Weights & Biases.
  • Phục vụ mô hình: FastAPI, Docker, các nền tảng cloud (SageMaker, Vertex AI).
  • Giám sát data drift, huấn luyện lại định kỳ, kiểm thử mô hình.
  • Machine Learning in Production (DeepLearning.AI) và sách Designing Machine Learning Systems (Chip Huyen).

6. Thực hành, thực hành, thực hành

  1. Làm lại các lab trong repo này không nhìn lời giải, bằng NumPy thuần.
  2. Cài lại vài thuật toán bằng PyTorch (hồi quy logistic, mạng 2 lớp, K-means trên GPU).
  3. Tham gia một cuộc thi Kaggle dạng bảng (dùng chương 11–12) và một cuộc thi ảnh/văn bản (dùng transfer learning).
  4. Xây một dự án hoàn chỉnh từ dữ liệu thô đến web demo (Streamlit/Gradio), viết blog giải thích — chính cuốn sổ tay này là một bước như vậy!
