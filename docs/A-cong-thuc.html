Bảng công thức tóm tắt

Mọi công thức quan trọng trong sách trên một trang — để ôn thi, phỏng vấn, hoặc khi cần tra nhanh lúc code. In ra được (Ctrl/Cmd + P).

Hồi quy tuyến tính (ch. 2–5)

Mô hình\(f_{\mathbf{w},b}(\mathbf{x}) = \mathbf{w}\cdot\mathbf{x} + b\)
Chi phí\(J = \frac{1}{2m}\sum_i \left(f(\mathbf{x}^{(i)}) - y^{(i)}\right)^2\)
Gradient\(\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum_i (f - y)x_j^{(i)}\), \(\;\frac{\partial J}{\partial b} = \frac{1}{m}\sum_i (f - y)\)
Cập nhật\(w_j := w_j - \alpha\frac{\partial J}{\partial w_j}\), \(\;b := b - \alpha\frac{\partial J}{\partial b}\) (đồng thời)
Normal equation\(\mathbf{w} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}\)
Z-score\(x_j := (x_j - \mu_j)/\sigma_j\)

Logistic regression (ch. 6)

Sigmoid\(g(z) = \frac{1}{1 + e^{-z}}\), \(\;g'(z) = g(z)(1-g(z))\)
Mô hình\(f = g(\mathbf{w}\cdot\mathbf{x} + b) = P(y=1\mid\mathbf{x})\)
Ranh giới\(\mathbf{w}\cdot\mathbf{x} + b = 0\)
Loss\(L = -y\log f - (1-y)\log(1-f)\)
Gradientgiống hồi quy tuyến tính: \(\frac{1}{m}\sum_i (f - y)x_j^{(i)}\)

Regularization (ch. 7)

Chi phí\(J + \frac{\lambda}{2m}\sum_j w_j^2\)
Gradient\(\frac{\partial J}{\partial w_j} + \frac{\lambda}{m}w_j\) (không áp cho \(b\))

Mạng nơ-ron (ch. 8–10)

Forward\(\mathbf{A}^{[l]} = g\left(\mathbf{A}^{[l-1]}\mathbf{W}^{[l]} + \mathbf{b}^{[l]}\right)\), \(\mathbf{A}^{[0]} = \mathbf{X}\)
Số tham số lớp Dense\(n_{\text{in}} \times n_{\text{out}} + n_{\text{out}}\)
ReLU\(\max(0, z)\)
Softmax\(a_j = e^{z_j}/\sum_k e^{z_k}\)
Cross-entropy\(L = -\log a_y\)
Backprop (lớp ra)\(\delta^{[L]} = \mathbf{A}^{[L]} - \mathbf{Y}\)
Backprop (lớp ẩn)\(\delta^{[l]} = (\delta^{[l+1]}\mathbf{W}^{[l+1]\top})\odot g'(\mathbf{Z}^{[l]})\), \(\;\nabla_{\mathbf{W}^{[l]}} = \frac{1}{m}\mathbf{A}^{[l-1]\top}\delta^{[l]}\)
Adam\(\mathbf m \leftarrow \beta_1 \mathbf m + (1-\beta_1)\nabla\), \(\mathbf v \leftarrow \beta_2\mathbf v + (1-\beta_2)\nabla^2\), \(\mathbf w \leftarrow \mathbf w - \alpha\hat{\mathbf m}/(\sqrt{\hat{\mathbf v}}+\epsilon)\)
Bài toánLớp raLoss (Keras)
Nhị phânDense(1, 'linear')BinaryCrossentropy(from_logits=True)
Đa lớpDense(N, 'linear')SparseCategoricalCrossentropy(from_logits=True)
Hồi quyDense(1, 'linear')MeanSquaredError()

Cây quyết định (ch. 12)

Entropy\(H(p_1) = -p_1\log_2 p_1 - (1-p_1)\log_2(1-p_1)\)
Information gain\(H(p_1^{\text{node}}) - \left(w^{\text{left}}H(p_1^{\text{left}}) + w^{\text{right}}H(p_1^{\text{right}})\right)\)
Gini\(1 - \sum_k p_k^2\)

Học không giám sát (ch. 13–15)

K-means: gán\(c^{(i)} = \arg\min_k\|\mathbf{x}^{(i)} - \boldsymbol\mu_k\|^2\)
K-means: dời tâm\(\boldsymbol\mu_k = \text{mean}\{\mathbf{x}^{(i)} : c^{(i)} = k\}\)
Distortion\(J = \frac{1}{m}\sum_i\|\mathbf{x}^{(i)} - \boldsymbol\mu_{c^{(i)}}\|^2\)
Gauss\(p(x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)\)
Anomaly\(p(\mathbf{x}) = \prod_j p(x_j;\mu_j,\sigma_j^2) < \varepsilon\)
PCA\(\mathbf{Z} = \mathbf{X}_c\mathbf{U}_K\), \(\hat{\mathbf X} = \mathbf Z\mathbf U_K^\top\)

Hệ gợi ý (ch. 16)

Dự đoán\(\mathbf{w}^{(j)}\cdot\mathbf{x}^{(i)} + b^{(j)} (+\mu_i)\)
Chi phí CF\(\frac12\sum_{r(i,j)=1}(\mathbf{w}^{(j)}\cdot\mathbf{x}^{(i)} + b^{(j)} - y^{(i,j)})^2 + \frac\lambda2\|\mathbf W\|^2 + \frac\lambda2\|\mathbf X\|^2\)
Content-based\(\hat y = \mathbf{v}_u\cdot\mathbf{v}_m\)

Học tăng cường (ch. 17)

Return\(R_1 + \gamma R_2 + \gamma^2R_3 + \dots\)
Bellman\(Q(s,a) = R(s) + \gamma\max_{a'}Q(s',a')\)
Chính sách\(\pi(s) = \arg\max_a Q(s,a)\)
Nhãn DQN\(y = R + \gamma\max_{a'}\hat Q(s',a')\cdot(1 - \text{done})\)
Soft update\(\mathbf w_{\hat Q} \leftarrow \tau\mathbf w_Q + (1-\tau)\mathbf w_{\hat Q}\)

Thực chiến (ch. 27–31)

Trọng số lớp\(w_c = \dfrac{N}{C \cdot N_c}\) · nhị phân: pos_weight \(= N_{\text{âm}}/N_{\text{dương}}\)
Residual\(\mathbf{y} = \mathbf{x} + F(\mathbf{x})\)
Autoencoder\(L = \|\mathbf{x} - g(f(\mathbf{x}))\|^2\); bất thường nếu sai số tái tạo > ngưỡng
VAE\(L = \|\mathbf{x}-\hat{\mathbf{x}}\|^2 + \beta\cdot\frac12\sum_j(\mu_j^2+\sigma_j^2-\log\sigma_j^2-1)\)
